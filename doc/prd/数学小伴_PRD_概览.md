# 数学小伴 — PRD 概览

| 项目 | 内容 |
|---|---|
| **产品名称** | 数学小伴 |
| **目标用户** | 初三女生（单人使用） |
| **模块名称** | 多会话管理 |
| **端类型** | 全部（后端云函数 + 微信小程序） |
| **当前状态** | 会话列表已实现，新建/删除/重命名/切换待开发 |

---

## 1. 项目背景

数学小伴是一款面向初三女生的 AI 数学学习助手，以粉白色小兔子角色通过苏格拉底式对话、故事化教学等方式帮助用户学习数学。当前已具备单会话对话能力，但随着用户使用频次增加，**多会话管理**成为提升体验的核心需求——用户需要能管理多个独立的学习对话，例如分别讨论"二次函数""相似三角形""圆"等不同知识点，并在不同会话间自由切换。

## 2. 功能总览

本模块覆盖 5 个子功能：

| # | 功能 | 端 | 优先级 | 当前状态 |
|---|---|---|---|---|
| 1 | 会话列表展示 | 小程序 | P0 | ✅ 已实现（记忆页） |
| 2 | 新建会话 | 小程序 + 后端 | P0 | ❌ 待开发 |
| 3 | 删除会话 | 小程序 + 后端 | P0 | ❌ 待开发 |
| 4 | 重命名会话 | 小程序 + 后端 | P1 | ❌ 待开发 |
| 5 | 会话内切换 | 小程序 | P0 | ❌ 待开发 |

## 3. 用户体验旅程

### 3.1 核心流程

```
用户进入小程序
  ├─ 对话页（默认展示最近一次的会话）
  │    ├─ 在当前会话中继续对话
  │    ├─ 点击「+」新建会话 → 自动切换到新会话
  │    └─ 点击顶栏切换按钮 → 弹出会话列表 → 选择会话切换
  │
  └─ 记忆页（Tab "记忆"）
       ├─ 查看所有历史会话列表（已有）
       ├─ 点击会话 → 跳转到对话页并加载该会话
       ├─ 左滑（或长按）会话 → 删除 / 重命名
       └─ 点击「新建」→ 跳转到对话页的新会话
```

### 3.2 页面关联

- 当前小程序 Tab：**对话** | **记忆** | **设置**
- **对话页**（`pages/chat/chat`）新增顶栏会话切换能力
- **记忆页**（`pages/memory/memory`）增强为完整会话管理中心
- 两页之间的跳转保持 `sessionId` 传递一致

## 4. AI 选型

| 项目 | 内容 |
|---|---|
| **AI 模型** | DeepSeek API（使用已有集成） |
| **AI 角色** | 粉白色小兔子「小伴」 |
| **性格** | 温柔耐心、鼓励式引导、从不批评、会用故事讲解数学 |
| **外观** | 粉白色毛茸茸小兔子，有长长的耳朵和粉红色蝴蝶结 |
| **语气** | 亲切可爱的少女风格，使用"~""呀"等语气词，配以颜文字和表情 |

> 多会话管理不涉及 AI 能力的变更，复用现有 DeepSeek + 策略引擎。

## 5. 非功能性需求

| 需求 | 说明 |
|---|---|
| 响应速度 | 会话列表加载 ≤ 2s，切换会话 ≤ 1s |
| 数据安全 | 删除采用软删除（标记 `isDeleted=true`），保留数据可恢复 |
| 会话数量上限 | 单个用户最多 100 个活跃会话 |
| 消息数量上限 | 单个会话最多 1000 条消息 |
| 离线可用 | 切换会话时本地缓存当前会话消息 |
