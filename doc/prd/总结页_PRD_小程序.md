## 1. 产品背景

### 1.1 业务目标

在「数学小伴」微信小程序中，提供一个清晰、美观、有激励性的学习总结页面，让用户每次打开都能感受到进步，增强持续学习的动力。

### 1.2 范围

**范围内**：
- 学习统计数据卡片展示（学习天数/学习次数/消息数/知识点数）
- 知识点掌握进度条展示
- 学习建议列表展示
- AI「小伴说」总结展示
- 数据范围切换（近期 / 全部）
- 空状态引导（无数据时）

**范围外**：
- 分享总结页到微信好友或朋友圈
- 学习数据导出

## 2. 用户与场景

### 2.1 目标用户

使用「数学小伴」微信小程序学习数学的中小学生，以及关心孩子学习进度的家长。

### 2.2 用户使用路径

| 场景 | 入口 | 操作 |
|------|------|------|
| 用户想了解学习进度 | 底部 Tab「总结」 | 点击 Tab 进入总结页，自动加载数据 |
| 用户想查看更多历史数据 | 总结页 | 点击切换按钮切换到「全部」范围 |
| 用户无学习记录 | 总结页 | 看到空状态引导，点击「开始学习」跳转到对话页 |

## 3. 功能需求

### 3.1 页面结构

总结页包含以下区域（从上到下）：

1. **顶部标题区**：渐变背景 + 页面标题「📊 学习总结」+ 副标题
2. **统计卡片区**：四个卡片横向排列，展示核心数据
3. **范围切换控件**：「近期学习」/「全部历史」切换
4. **知识点进度区**：每个知识点一个进度条，展示名称、等级、练习次数
5. **学习建议区**：个性化建议列表
6. **AI 总结区**：「小伴说」卡片，展示 AI 生成的鼓励总结

### 3.2 统计卡片

| 卡片 | 展示内容 | 数据来源 |
|------|---------|---------|
| 学习天数 | 数字 + "学习天数" 标签 | 后端统计 |
| 学习次数 | 数字 + "学习次数" 标签 | 后端统计 |
| 对话消息 | 数字 + "对话消息" 标签 | 后端统计 |
| 知识点 | 数字 + "知识点" 标签 | 后端统计 |

**验收标准**：

> **AC-1**：四个统计卡片横向等宽排列，每个卡片显示数字和标签
>
> Given 用户有学习数据
> When 用户进入总结页
> Then 显示学习天数、学习次数、对话消息、知识点四个卡片，数字居中显示

> **AC-2**：数字从 0 动画增长到实际值
>
> Given 用户有 15 天学习记录
> When 总结页加载完成
> Then 学习天数卡片从 0 动画增长到 15

### 3.3 知识点进度

每个知识点展示：
- 知识点名称（左对齐）
- 等级文字标签（右对齐，如「掌握」「熟练」）
- 进度条（按掌握程度填充百分比）
- 练习次数和掌握百分比（底部）

**验收标准**：

> **AC-3**：知识点按掌握程度从低到高排序，让用户优先看到需要加强的知识点
>
> Given 用户有 3 个知识点
> When 进入总结页
> Then 知识点按掌握程度从低到高排列

> **AC-4**：进度条宽度与掌握程度百分比一致，且有渐变颜色过渡动画
>
> Given 某知识点掌握程度为 65%
> When 进入总结页
> Then 进度条填充宽度为 65%，颜色为粉色渐变

### 3.4 学习建议

- 以毛玻璃风格卡片展示
- 每条建议前带 emoji 图标
- 根据学习数据动态生成，不硬编码

**验收标准**：

> **AC-5**：当有 2 条以上建议时，全部展示
>
> Given 生成了 3 条学习建议
> When 进入总结页
> Then 3 条建议全部展示，每条居中对齐

### 3.5 AI「小伴说」

- 独立卡片区域，标题「🌟 小伴说」
- 展示 AI 生成的总结文字
- 文字以亲切鼓励的语气表述
- 纯文字展示，无需用户操作

**验收标准**：

> **AC-6**：AI 总结文字完整显示，不截断
>
> Given 后端返回了总结文字
> When 进入总结页
> Then 总结文字完整显示在「小伴说」卡片中

### 3.6 数据范围切换

- 在统计卡片下方提供「近期学习」/「全部历史」两个选项
- 用户点击切换后，重新加载对应范围的数据
- 当前选中项有高亮样式

**验收标准**：

> **AC-7**：点击「全部历史」后，数据刷新为全部范围的数据
>
> Given 当前显示近期数据
> When 用户点击「全部历史」
> Then 页面重新加载全部范围的数据，且「全部历史」按钮高亮

### 3.7 空状态

当用户没有任何学习记录时，展示：
- 📚 大号书籍 emoji
- "还没有学习记录" 提示文字
- "快来开始你的数学之旅吧！" 引导文字
- 「开始学习」按钮，点击跳转到对话页

**验收标准**：

> **AC-8**：当用户没有学习记录时，只显示空状态界面，不显示统计卡片等区域
>
> Given 用户从未学习过
> When 进入总结页
> Then 只显示空状态引导，不显示统计数据

### 3.8 加载状态

- 数据加载中显示旋转动画和「加载中...」提示
- 加载失败时显示空状态，不报错弹窗

## 4. 页面流转

| 触发 | 目标 | 方式 |
|------|------|------|
| 点击底部 Tab「总结」 | 总结页 | Tab 切换 |
| 空状态「开始学习」按钮 | 对话页 | `wx.switchTab` |
| 点击「近期学习」| 重新加载本页数据（近期范围） | 页面内刷新 |
| 点击「全部历史」| 重新加载本页数据（全部范围） | 页面内刷新 |

## 5. UI 风格要求

### 5.1 整体风格

- 延续「数学小伴」整体设计语言：**苹果风、圆润、柔和**
- 主色调：粉色系渐变（#FF7EB3 → #FF5CA8）
- 卡片背景：白色带轻微阴影
- 圆角：大圆角（24rpx ~ 48rpx）

### 5.2 字体与排版

- 数据数字：大号粗体（44rpx），粉色显示
- 标签文字：小号（22rpx），灰色
- 标题：32rpx 粗体
- 正文：28rpx

### 5.3 动画

- 统计数字从 0 增长到实际值（入场动画）
- 进度条从左到右填充动画
- 页面切换有平滑过渡
- 列表项加载后渐入

## 6. 非功能需求

| 需求 | 说明 | 优先级 |
|------|------|--------|
| 页面加载速度 | 从进入页面到数据展示不超过 3 秒 | P0 |
| 离线容错 | 网络异常时显示空状态，不白屏不崩溃 | P0 |
| 动画流畅度 | 列表滚动 60fps，无卡顿 | P1 |
