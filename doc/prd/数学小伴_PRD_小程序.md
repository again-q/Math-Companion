# 数学小伴 — PRD 小程序（多会话管理）

| 项目 | 内容 |
|---|---|
| **端类型** | 微信原生小程序 |
| **涉及页面** | `pages/chat/chat`（对话页）、`pages/memory/memory`（记忆页） |
| **视觉风格** | 粉嫩可爱风（樱花粉 #FFB5C2 / 奶油白 #FFF0F3 / 嫩粉 #FF7EB3） |

## 1. 页面设计

### 1.1 对话页（`chat/chat`）— 顶部增加会话切换栏

**当前布局**（自上而下）：
1. 兔子角色展示区 + 模式标签
2. 消息列表（scroll-view）
3. 底部输入区（语音按钮 + 输入框 + 发送按钮）

**新增设计：在角色展示区上方增加「会话切换栏」**

```
┌──────────────────────────────────┐
│  [←] 会话标题          [▼]  [+ ]│  ← 会话切换栏（新增）
├──────────────────────────────────┤
│         🐰  [苏格拉底模式]       │  ← 角色展示区（已有）
├──────────────────────────────────┤
│  消息列表...                      │
│                                   │
├──────────────────────────────────┤
│  🎤  [输入框……]          发送    │  ← 输入区（已有）
└──────────────────────────────────┘
```

#### 会话切换栏设计

| 元素 | 位置 | 交互 | 说明 |
|---|---|---|---|
| 返回按钮 `←` | 最左侧 | 点击弹出会话列表抽屉（从左侧滑出） | 包含微小的弹簧动画 |
| 会话标题 | 居中 | 点击 = 点击 `←` 效果 | 显示当前会话的 `title`，最多 15 字后加"..." |
| 下拉箭头 `▼` | 标题右侧 | 点击展开下拉菜单 | 呼出会话切换下拉面板 |
| 新建按钮 `+` | 最右侧 | 点击创建新会话 | 立即创建并切换到新会话，标题暂显示"新对话" |

#### 下拉切换面板设计

```
┌──────────────────────────────────┐
│  📝 新建对话                     │
├──────────────────────────────────┤
│  ● 二次函数顶点式讨...   10:30  │  ← 当前会话标记 ●
│  ○ 相似三角形的判定      昨天    │
│  ○ 圆的切线与证明       1月12日 │
│  ○ 锐角三角函数         1月10日 │
│  ○ 一元二次方程解法     1月8日   │
├──────────────────────────────────┤
│  查看更多 ›                      │
└──────────────────────────────────┘
```

- 下拉面板最多显示最近 5 条会话
- 当前会话用实心圆点 `●` 标记
- 点击非当前会话 → 切换并关闭面板
- 点击"查看更多" → 跳转到记忆页
- 点击外部区域 → 关闭面板
- 面板背景白色，圆角 16rpx，带轻微阴影

### 1.2 记忆页（`memory/memory`）— 增强为会话管理中心

**当前记忆页布局**：顶部学习总结卡片 + 会话列表（仅展示，可跳转）

**增强设计**：

```
┌──────────────────────────────────┐
│  📊 学习总结          >         │  ← 学习总结卡片（保留）
├──────────────────────────────────┤
│  历史对话                        │
│                                  │
│  ┌──────────────────────────┐   │
│  │ 二次函数顶点式讨...      │   │  ← 会话卡片
│  │ 1月15日 10:30 · 12条消息  │   │
│  │        [重命名] [删除]   │   │  ← 操作按钮
│  └──────────────────────────┘   │
│                                  │
│  ┌──────────────────────────┐   │
│  │ 相似三角形的判定         │   │
│  │ 1月14日 15:20 · 8条消息   │   │
│  │        [重命名] [删除]   │   │
│  └──────────────────────────┘   │
│                                  │
│       [+ 新建对话]               │  ← 新建按钮
└──────────────────────────────────┘
```

#### 会话卡片增强

| 元素 | 说明 |
|---|---|
| 标题 | 显示 `title`，无标题时显示"未命名对话"（灰色斜体） |
| 时间 | 显示格式：当天的显示时间，昨天的显示"昨天"，更早显示"X月X日" |
| 消息数 | "X 条消息" |
| 重命名按钮 | 点击弹出重命名弹窗 |
| 删除按钮 | 点击弹出二次确认删除弹窗 |
| 手势支持 | 左滑显示"删除"红色操作按钮（类似 iOS 邮件列表） |

#### 交互操作

**新建对话**：
- 方式 1：页面底部 "+ 新建对话" 按钮 → 创建会话 → 跳转到对话页
- 方式 2：对话页顶栏右侧 "+" 按钮

**删除会话**（BR-010）：
- 点击删除 → 弹窗确认："确定删除「二次函数顶点式...」？删除后不可撤销，但消息记录仍保留在你的数据中。"
- 确认后调用云函数软删除 → 列表移除该条目
- 若仅剩最后一条会话（BR-008），弹窗提示"至少保留一个会话哦~"

**重命名会话**：
- 点击重命名 → 弹出带输入框的弹窗
- 输入框预填当前标题
- 限制 50 字（BR-009）
- 点击确定 → 调用云函数 → 更新列表显示

### 1.3 空状态与边界情况

| 场景 | 对话页表现 | 记忆页表现 |
|---|---|---|
| 无任何会话 | 显示欢迎语"你好呀~我是小伴🐰..."，顶栏显示"开始学习吧" | 显示"还没有学习记录，开始第一次对话吧~" + 新建按钮 |
| 全部会话已删除 | 同"无任何会话" | 同"无任何会话" |
| 加载失败 | 显示 Toast "会话列表加载失败" + 保留当前会话 | 显示 Toast "加载失败" + 保留上次缓存 |
| 切换会话时网络差 | 加载中显示骨架屏，超时 10s 提示"网络开小差了~" | — |

## 3. 视觉风格

### 3.1 色彩规范

| 角色 | 色值 | 用途 |
|---|---|---|
| 主题粉 | `#FF7EB3` | 按钮、选中态、高亮 |
| 背景粉 | `#FFF0F3` | 页面背景 |
| 导航粉 | `#FFB5C2` | 导航栏、顶栏背景 |
| 奶油白 | `#FFFFFF` | 卡片、输入框背景 |
| 文字主色 | `#333333` | 标题文本 |
| 文字次要 | `#9B9B9B` | 时间、消息数、辅助文字 |
| 危险红 | `#FF3B30` | 删除按钮、警告提示 |

### 3.2 会话切换栏样式

| 属性 | 值 |
|---|---|
| 高度 | 88rpx（包含上下 padding） |
| 背景色 | `#FFB5C2`（导航粉，与顶栏一致） |
| 文字颜色 | `#FFFFFF` |
| 字号 | 32rpx（标题），28rpx（图标） |
| 圆角 | 无（通栏设计） |
| 分割线 | 下方 1rpx `#FF9EB0` |

### 3.3 下拉面板样式

| 属性 | 值 |
|---|---|
| 背景 | `#FFFFFF`，圆角 16rpx |
| 阴影 | 0 4rpx 20rpx rgba(0,0,0,0.12) |
| 最大高度 | 70vh（可滚动） |
| 条目高度 | 100rpx |
| 分割线 | 条目间 1rpx `#F0F0F0` |
| 当前会话标记 | 粉色实心圆点 `●` `#FF7EB3` |

### 3.4 动画与过渡

| 交互 | 动画 | 时长 |
|---|---|---|
| 下拉面板展开 | 淡入 + 向下展开 | 200ms |
| 切换会话 | 消息列表淡出 → 新列表淡入 | 250ms |
| 左滑删除 | 跟随手指平移 + 回弹 | 按手势速度 |
| 新建会话 | 按钮缩放 1.1→1.0 + 页面切换 | 150ms |
