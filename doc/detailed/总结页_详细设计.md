## 1. 后端详细设计

### 1.1 generateSummary 逻辑

**文件**: `cloudfunctions/math-agent/services/conversation.js` 中的 `generateSummary()` 函数

**参数**:
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| scope | string | 'recent' | 'recent' = 最近 10 条; 'all' = 最近 100 条 |

**返回值**:
```javascript
{
  summary: string,        // AI 总结文字
  topicsCovered: Array,    // [{ topic, level, practicedCount, consecutiveCorrect, levelDesc }]
  totalSessions: number,   // 学习会话数
  totalMessages: number,   // 总消息数
  learningDays: number,    // 学习天数
  stats: {                 // 聚合统计
    masteredCount: number,
    learningCount: number,
    newCount: number,
    avgLevel: number
  },
  suggestions: Array<string>  // 建议列表
}
```

**实现步骤**:
1. 调用 `memory.getRecentSessions(limit)` 获取活跃会话列表
2. 若 sessions 为空，返回空数据（含欢迎语）
3. 计算 totalSessions / totalMessages / learningDays
4. 收集所有 topics，对每个 topic 调用 `memory.getTopicProgress(topic)`
5. 为每个 topic 生成 levelDesc 等级描述文字
6. 根据 masteredCount / learningCount 等统计数据生成 suggestions
7. 组装 summary 文字
8. 检查 mt_profile 中的 summaryNeedsUpdate 标记：若需要更新则重新生成 AI 总结并缓存；否则返回上次缓存的 summary

### 1.2 总结缓存

**文件**: `cloudfunctions/math-agent/services/conversation.js`

- 在 `handleMessage()` 中，每次成功处理消息后设置 `summaryNeedsUpdate = true`
- 在 `generateSummary()` 中，检查 `summaryNeedsUpdate`：
  - true：调用 DeepSeek 生成新 summary → 写入缓存 → 返回新内容
  - false：直接返回上次缓存的 summary

### 1.3 等级描述映射

```javascript
function getLevelDesc(level) {
  if (level < 0.3) return '初识';
  if (level < 0.5) return '了解';
  if (level < 0.7) return '掌握';
  if (level < 0.9) return '熟练';
  return '精通';
}
```

## 2. 小程序前端详细设计

### 2.1 页面数据模型

```javascript
data: {
  loading: true,           // 加载状态
  summary: '',             // AI 总结文字
  topicsCovered: [],       // 知识点进度列表
  stats: {},               // 聚合统计
  suggestions: [],         // 学习建议列表
  totalSessions: 0,
  totalMessages: 0,
  learningDays: 0,
  empty: false,            // 是否空数据
  scope: 'recent',         // 数据范围：'recent' | 'all'
}
```

### 2.2 生命周期

| 事件 | 行为 |
|------|------|
| onLoad | 调用 `loadSummary()` 加载数据 |
| onShow | 调用 `loadSummary()` 每次显示重新加载 |

### 2.3 交互

| 操作 | 行为 |
|------|------|
| 切换「全部历史」 | `setData({ scope: 'all' })` → `loadSummary()` |
| 切换「近期学习」 | `setData({ scope: 'recent' })` → `loadSummary()` |
| 点击「开始学习」（空状态按钮） | `wx.switchTab({ url: '/pages/chat/chat' })` |

### 2.4 动画

| 元素 | 动画 | 实现方式 |
|------|------|---------|
| 统计数字 | 从 0 增长到实际值 | JS 逐帧更新 |
| 进度条 | 从左到右填充 | CSS transition: width |
| 列表项 | 渐入 | CSS animation |

## 3. 接口定义

### 3.1 云函数调用

```javascript
// 前端 chat-service.js
function getSummary(scope = 'recent') {
  return wx.cloud.callFunction({
    name: 'math-agent',
    data: { type: 'getSummary', data: { scope } }
  });
}
```

### 3.2 数据库查询

```javascript
// memory.js - getRecentSessions
db.collection('mt_sessions')
  .where({ isDeleted: _.neq(true), status: 'active' })
  .orderBy('updatedAt', 'desc')
  .limit(limit)
  .get()

// memory.js - getTopicProgress
db.collection('mt_knowledge_progress')
  .where({ topic })
  .limit(1)
  .get()
```
