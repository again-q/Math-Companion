## 1. 通用规范

### 1.1 语言与版本

| 层 | 语言 | 版本 | 运行时 |
|----|------|------|--------|
| 云函数 | Node.js | 18.x | 微信云函数环境 |

### 1.2 命名规范

| 类别 | 规范 | 示例 |
|------|------|------|
| 云函数名 | kebab-case | `math-agent`, `memory-manager` |
| JS 变量/函数 | camelCase | `sessionId`, `loadContext()` |
| JS 类名 | PascalCase | `SessionManager`, `MemoryStore` |

| 小程序页面 | kebab-case | `pages/chat/chat` |
| 小程序组件 | kebab-case | `rabbit-avatar`, `mode-badge` |

- **缩进**：2 个空格

- **行尾分号**：始终加分号
- **行宽**：不超过 100 字符
- **尾逗号**：对象/数组多行时加尾逗号

### 2.2 云函数入口规范

```javascript
// index.js — 统一事件分发
const { sendMessage } = require('./handlers/sendMessage');
const { getSummary } = require('./handlers/getSummary');

exports.main = async (event, context) => {
  const { type, data } = event;
  
  // 统一错误处理包装
  try {
    switch (type) {
      case 'sendMessage':
        return await sendMessage(data, context);
      case 'getSummary':
        return await getSummary(data, context);
      default:
        return { code: 400, error: `未知事件类型: ${type}` };
    }
  } catch (err) {
    console.error(`[math-agent] 处理 ${type} 失败:`, err.message);
    return { code: 500, error: '服务内部错误，请稍后再试' };
  }
};
```

### 2.3 异步规范

- 所有数据库/API 操作必须使用 `async/await`
- 禁止在顶层使用 `.then()` `.catch()`
- 错误的 async 函数必须有 try-catch 包裹

### 2.4 环境变量

| 变量名 | 用途 | 设置方式 |
|--------|------|---------|
| `DEEPSEEK_API_KEY` | DeepSeek API 密钥 | 云函数环境变量 |
| `DEEPSEEK_BASE_URL` | API 基础地址 | 云函数环境变量 |
| `MAX_MESSAGES_PER_SESSION` | 单会话消息上限 | `config/index.js` 默认值 |

### 3.2 WXML 规范

- 使用语义化 class 命名，不直接使用内联 style
- 条件渲染使用 `wx:if` / `wx:elif` / `wx:else`
- 列表渲染使用 `wx:for` 并始终指定 `wx:key`
- 事件绑定使用 `bind` 前缀，不允许 `catch` 滥用

```html
<!-- ✅ 正确 -->
<view class="message-item {{item.role}}" wx:for="{{messages}}" wx:key="msgId">
  <view class="bubble {{item.role}}">{{item.content}}</view>
</view>

<!-- ❌ 错误 -->
<view style="padding: 10px;" wx:for="{{messages}}">
  <view>{{item.content}}</view>
</view>
```

### 3.3 WXSS 规范

- 使用 CSS 变量定义主题色
- 尺寸单位统一使用 rpx
- 避免过深的样式嵌套（不超过 3 层）

```css
/* ✅ 正确 */
page {
  --primary-color: #FFB5C2;
  --bg-primary: #FFF0F3;
  --text-primary: #4A4A4A;
}

.message-list {
  padding: 20rpx;
}

.bubble.user {
  background: #FFE4E9;
}

/* ❌ 避免 */
.message-list .item .content .inner .text { }
```

### 3.4 JS 规范

- 使用 `Page()` 构造器，不混用 `Component`
- 数据更新统一使用 `this.setData()`，不直接修改 `this.data`
- 频繁更新的场景（如打字效果）使用节流/防抖

```javascript
// ✅ 正确
Page({
  data: { count: 0 },
  onTap() {
    this.setData({ count: this.data.count + 1 });
  }
});

// ❌ 错误
Page({
  data: { count: 0 },
  onTap() {
    this.data.count++; // 不会触发视图更新
  }
});
```

## 4. 数据库规范

### 4.1 集合与文档

- 每个集合名使用小写 snake_case 复数
- 文档中的时间字段统一命名为 `createdAt` / `updatedAt`
- 时间值使用 Date 对象存储（微信云数据库自动序列化）
- 所有文档必须有 `_id`（由云数据库自动生成）

### 4.2 索引规范

- 查询频繁的字段必须建索引
- 复合索引按查询顺序（等值 → 排序）
- 索引命名规则：`idx_{field1}_{field2}`

### 4.3 数据访问

- 小程序前端不直连数据库，全部通过云函数代理
- 数据库权限设为"仅管理员写"（云函数内调用）
- 不创建安全规则（由云函数统一鉴权）

## 5. 错误处理规范

### 5.1 云函数错误返回格式

```javascript
// 成功
{ code: 0, data: { ... } }

// 客户端错误（参数错误等）
{ code: 400, error: '消息内容不能为空' }

// 服务端错误
{ code: 500, error: 'AI 服务暂时不可用，请稍后再试' }
```

### 5.2 小程序错误展示

- 网络错误：`wx.showToast({ title: '网络开小差了~', icon: 'none' })`
- 服务错误：`wx.showModal({ title: '提示', content: '小伴有点累了，稍后再试~' })`
- 输入校验：直接在输入框下方显示红色提示文字

## 6. 安全规范

| 规范 | 说明 |
|------|------|
| API Key 管理 | 存储在云函数环境变量，不硬编码，不传至前端 |
| 日志脱敏 | 不输出完整对话内容，只记录长度和操作类型 |
| 输入过滤 | 对用户输入做 XSS 防护（小程序自动处理，但云函数也应校验） |
| 调用频率 | 云函数内对 DeepSeek API 做好错误重试（最多 2 次） |
| 会话清理 | 消息超过 1000 条时自动归档最早消息 |
